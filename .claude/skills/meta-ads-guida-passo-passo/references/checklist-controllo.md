# Checklist di controllo (Fase 5)

Da fare con lo studente prima di attivare qualsiasi cosa, voce per voce. Le voci **B** (bloccanti) vanno
sistemate tutte; le **A** (avvisi) si spiegano e decide lo studente.

Colonna "Come": **S** = screenshot dello studente · **C** = connettore in sola lettura (se scelto nel setup;
altrimenti screenshot) · **F** = script sui file.

## File e libreria

| Voce | Come | Grav. |
|---|---|---|
| `creativita.py verifica` con zero errori | F | B |
| Ogni inserzione ha due file distinti in libreria, nomi identici ai file | S/C | B |
| Video in libreria in stato pronto (non in elaborazione) | S/C | B |
| Nessun video muto non voluto | F | A |

## Campagna

| Voce | Come | Grav. |
|---|---|---|
| Nome secondo lo schema, maiuscolo | S/C | B |
| Obiettivo coerente: ACQUISIZIONE = Contatti, VENDITA = Vendite | S/C | B |
| Nessun budget di campagna | S/C | B |
| In pausa | S/C | B |
| Creata da zero (nessun "- Copia" nei nomi) | S/C | B |

## Gruppi di inserzioni (ognuno)

| Voce | Come | Grav. |
|---|---|---|
| Nome secondo lo schema | S/C | B |
| Un gruppo per tipologia del piano, nessuno vuoto; in retargeting sia "Visite al sito" sia "Engage social" | S/C | B |
| Budget giornaliero = piano | S/C | B |
| Pixel del setup, evento Lead o Acquisto coerente con l'obiettivo | S/C | B |
| Obiettivo di prestazioni: massimizza conversioni · offerta: volume più alto | S/C | B |
| Attribuzione: Lead 1 giorno clic + 1 visualizzazione · Vendite 7 giorni clic + 1 visualizzazione | S/C | B |
| Date di inizio e fine = piano | S/C | B |
| Paesi del setup, nessuna lingua | S/C | B |
| Prospecting: nessun pubblico personalizzato, nessun interesse | S/C | B |
| Retargeting: pubblici giusti, Engage IG e FB nello stesso gruppo, Pubblico Advantage+ disattivato | S/C | B |
| Lead: nessuna esclusione · Vendite: lista clienti esclusa su ogni gruppo | S/C | B |
| Posizionamenti Advantage+ | S/C | B |
| Inserzionista e pagante del setup | S | B |
| Pubblici molto piccoli (poche decine di persone) | S/C | A |
| Età diversa da 18-65 senza motivo | S/C | A |

## Inserzioni (ognuna)

| Voce | Come | Grav. |
|---|---|---|
| Nome dalla lista inserzioni, senza feed/story/+1/estensione | S/C | B |
| Numero di inserzioni per gruppo = creatività del piano, nessun doppione | S/C | B |
| Pagina e account Instagram del setup | S | B |
| File feed sui Feed, file story su Storie e Reel, nessun quadrato nelle Storie | S | B |
| Testi e titoli = versione approvata, uguali in tutto il gruppo, descrizione vuota | S | B |
| Invito all'azione del setup | S | B |
| URL senza utm attaccati · "Parametri URL" compilati col valore del setup | S | B |
| Miglioramenti creativi Advantage+ tutti spenti | S | B |
| Nessun errore nella colonna "Consegna", ricontrollato dopo qualche minuto | S/C | B |
| Inserzioni con più inserzionisti attivo | S | A |

## Chiusura

Tutte le B a posto: lo studente attiva dall'alto verso il basso (campagna, gruppi, inserzioni). Dopo
l'attivazione fai ricontrollare paese e stato: a volte Meta li ritocca alla pubblicazione.
