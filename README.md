# Campagne Meta · guida passo passo

Una cartella per Claude Code che ti accompagna dalle creatività appena scaricate alla campagna Meta pronta,
in pausa e controllata. Le operazioni le fai tu, Claude ti guida un passo alla volta e controlla il risultato.

## Scarica

**[Scarica Campagne-Meta.zip](https://github.com/pierpaolotomaselli12-hub/campagne-meta-guida/releases/latest/download/Campagne-Meta.zip)**

## Come si parte

1. Estrai lo zip (doppio clic) e sposta la cartella `Campagne-Meta` dove preferisci, per esempio in Documenti.
2. Apri l'app Claude sul computer, vai nella scheda **Code** e scegli la cartella `Campagne-Meta`.
3. Se l'app chiede se ti fidi della cartella, rispondi di sì.
4. Scrivi **iniziamo**.

La prima volta Claude ti guida nel setup del tuo account Meta. Tutti i dettagli sono nel file `LEGGIMI.md`
dentro la cartella.
